## 宗师棋力优化（实现与对照验收完成）

目标：在 30×30、每手 4 秒预算内提高合法落子和战术判断质量。保留现有评分缓存、局部更新、α-β、置换表与 Worker 架构。用户已以 OK 确认实施。

### 已证实的问题

- 搜索树忽略黑方禁手；合法历史 `K15 AD30 L15 AD28 M15 AD26 O15 AD24 P15 AD22` 后，宗师把 N15 长连当作必胜；主线程剔除后改下 A30。新旧引擎都有此问题。
- 裁判本身漏判交叉跳活三：黑方已有 O15、R15、P16、P13，再下 P15 返回非禁手；横向补 Q15、纵向补 P14 都合法且能形成两端成五的活四。
- VCF 子搜索可以耗尽整手预算，导致普通搜索没有完整层结果；可控单调时钟已复现深度 0 返回，不能据此推断用户对局的实际触发频率。
- 固定“时间超过一半就不再加深”的策略较保守；宗师实测分散局面 2.13 秒完成 7 层后停止。该策略在优化前已存在。

- [x] 根候选、每层黑方落子、双方成五点、VCF 攻方落点及防方应手均判断合法性。棋型总分用于排序，必胜结论须来自合法成五或已证实的强制杀法。
- [x] 候选限额按合法着法计数；禁手被跳过后继续取后续候选。引擎提供经评分的合法落子，删除主线程“找第一个合法空点”的自动替代；校验失败显式报告引擎错误。
