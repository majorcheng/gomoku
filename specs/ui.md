# UI 界面与交互设计规范 (UI Specification)

沿用 02.chess / 03.chess_master 的视觉语言与布局骨架（顶部标题比分栏 /
中间主对局区 / 侧边引擎面板 / 对局总结浮层 / 底部说明区块），针对五子棋的
**Canvas 棋盘**、**悬停预览**、**胜利连线**与**迭代加深实时进度**做定制。

---

## 2. 核心 UI 组件与交互细则

### 2.1 顶部标题与比分栏 (`#content-title`)

* **圆形计分徽章 (`.title-counter`)**：左侧 `#black-counter`（黑棋底色）、
  右侧 `#white-counter`（白棋底色），显示双方胜局数（跨局累计，存
  `localStorage`，键 `gomoku-counters`）。
* **主标题 (`#title`)**：居中艺术标题「五 子 棋」。

### 2.2 棋盘外框与多级菜单遮罩 (`#board-options`)

未开局或回到菜单时遮罩浮于棋盘上方，层级与 02/03 一致：

1. **主菜单**：【开始对局】/【说明】
2. **模式选择菜单**：【人机对战】`#pvebtn` /【本机双人】`#pvpbtn` /
   【机机对战】`#evebtn` /【返回】
3. **执子选择菜单**（仅人机模式进入）：【我执黑（先行）】/【我执白（后行）】/【返回】
4. **难度选择菜单**（人机/机机模式进入）：六档按钮（入门 / 初级 / 中级 /
   高级 / 大师 / 宗师），与 `difficulty.js` 的 `LEVELS` 一一对应，
   **从该文件动态生成**，不硬编码文案。选中档位高亮，可改选后再开始。

> 本机双人模式跳过执子与难度两步，直达对局——五子棋双人无需选边。

### 2.3 棋盘 (`#board`，Canvas 渲染) ★本项目特有

* **渲染方式**：单 `<canvas>`，按 `devicePixelRatio` 缩放保证高清，
  `ResizeObserver` 跟随容器自适应重绘。
* **视觉**：木色棋盘（与系列木色 token 一致）、15×15 细线网格、
  五个星位圆点（(3,3) (3,11) (11,3) (11,11) (7,7)）、四周 `A..O` / `1..15`
  坐标标注。
* **棋子**：程序化径向渐变——黑子高光偏左上、白子带浅灰描边，
  无任何图片资源。
* **交互能力**：
  * **悬停预览**：鼠标移到空交叉点显示半透明预览棋子；
  * **点击落子**：点击空点落子（已有棋子/终局/非人回合时忽略）；
  * **最后一手标记**：最新落子中心画红色小点；
  * **胜利连线**：终局时把获胜五连的首尾棋子中心用高亮线段连出，
    获胜棋子外圈发光描边。
* **落子动画**：棋子以 120ms 缩放淡入（Canvas 每帧重绘实现），
  不做位移动画（五子棋没有「移动」语义）。

### 2.4 竖向评估条 (`#eval-bar`)

* 贴在棋盘一侧的细长条，**黑方优势向上填黑、白方优势向下填白**。
* 数值来自引擎搜索分（黑方视角），经 `tanh(score / 20000)` 压缩到 ±1。
  必胜分（≥ WIN 阈值）显示满格并标 `胜`。
* 无数据时中线平分；人机执白时评估条不翻转（始终黑上白下，
  与棋盘方向无关，降低认知负担）。

### 2.5 侧边引擎面板 (`<aside id="ai-panel">`)

* **外观**：深色现代科技卡片，与 02/03 完全一致的 token 与阴影。
* **对局信息区**：模式、难度、当前行棋方（含「引擎思考中」态）、
  最近落子坐标、总手数。
* **搜索数据表格 (`#ai-stats-table`)**：列定义
  `# | 方 | 来源(玩家/AI) | 落子 | 深度 | 节点 | NPS | 耗时 | 分数`，
  与 02/03 一致（`.source-human` / `.source-ai` 区分来源）。
  * 落子列显示坐标（如 `H8`）；
  * 来源列有三个值：玩家 / AI / `AI·次优` / `AI·VCF`（如实标注）；
  * 分数列黑白视角统一为**黑方视角**（正 = 黑优），蓝/黄配色区分正负。
* **底部实时状态栏 (`#ai-current`)**：迭代加深时显示
  `深度 6 · 82,341 节点 · 410k NPS`（数据来自 `info` 消息，真实非动画）；
  空闲时显示就绪状态。
* **引擎卡 (`#engine-facts`)**：显示当前生效的算法参数
  （深度上限/时限/候选宽度/温度/失误率/VCF 开关），读自 `difficulty.js`。

### 2.6 对局总结浮层 (`#game-summary`)

* 终局时弹出居中蒙版。
* 文案必须**区分成因**：`黑方五连获胜` / `白方五连获胜` /
  `和棋 — 棋盘已满`，并显示获胜连线的起止坐标（如 `H8 → L12`），
  不得统一写成「游戏结束」。
* 按钮：【再来一局】`#summary-restart`、【看看棋盘】`#summary-close`
  （关闭浮层保留胜利连线供复盘）。
* **悔棋按钮**在常驻控制区提供；人机对局一次撤回两步，双人一步。

### 2.7 底部说明区块 (`#engine-note`)

说明自研引擎的算法组成（迭代加深 α-β / 置换表 / VCF）、零依赖特性、
GitHub Pages 可部署、以及源码仓库链接。

## 3. CSS Tokens 与样式分布规范

`styles/tokens.css` 取值（继承系列深色科技风，换五子棋木色棋盘 token）：

```css
:root {
  /* 颜色 */
  --color-bg-primary: #727272;
  --color-panel-bg: #20242b;
  --color-text-main: #e8eaef;
  --color-text-muted: #aeb5c2;
  --color-score-positive: #78c7ff;
  --color-score-negative: #ffd36b;
  --color-brand: #8c2d19;
  --color-accent: #27ae60;
  --color-board-wood: #d6b17c;
  --color-board-line: #6b4a2b;
  --color-eval-black: #2b2b2b;
  --color-eval-white: #f2f2f2;

  /* 布局 */
  --board-size: clamp(360px, min(56vw, 76vh), 1080px);
  --panel-width: clamp(480px, 26vw, 620px);
  --eval-bar-width: 16px;
  --eval-bar-gap: 10px;
}
```

**样式目录结构**（禁止把所有样式写进单个文件）：

```text
styles/
├── tokens.css              # 变量定义
├── base.css                # 重置与排版
├── components/
│   ├── layout.css          # 整体 Grid/Flex 布局与响应式
│   ├── board.css           # 棋盘外壳、Canvas 容器、评估条
│   ├── panel.css           # 侧边栏、搜索数据表格
│   ├── controls.css        # 按钮组、计分徽章
│   └── modal.css           # 多级菜单遮罩、对局总结浮层、toast
└── main.css                # 统一 @import 入口
```

### 3.1 响应式无溢出

沿用 `aspect-ratio` + `clamp()`：棋盘容器 `aspect-ratio: 1 / 1`，
宽度 `min(100%, var(--board-size))`；桌面端 `@media (min-width: 768px)` 切为
`grid-template-columns: minmax(320px, var(--board-size)) var(--panel-width)` 双栏；
窄屏单栏堆叠，棋盘在上。

### 3.2 可访问性

* 棋盘 `canvas` 带 `role="img"` 与动态 `aria-label`（如「第 12 手，轮到白方」）；
* 所有按钮为真实 `<button>`，焦点样式可见；
* 悬停预览与最后一手标记同时使用颜色 + 形状双重编码（红点 / 发光圈），
  不单靠颜色区分。
